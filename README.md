# AutoRewriter
Auto query rewriting engine base on large scale rewrite rules

## Build

1. build sharedingshere

```
git clone https://github.com/TiNnNnnn/shardingsphere

cd shardingsphere

mvn install -DskipTests
```

2. build AutoRewriter

```
git clone https://github.com/TiNnNnnn/AutoRewriter

cd AutoRewriter

./install-local-jars.sh  

mvn install -DskipTests

```
